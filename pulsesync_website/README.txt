NOVATECH SOLUTIONS | PULSESYNC WEBSITE (ORIGINAL BUILD UPDATED)

CONTENTS
- index.html: single-page support portal with ticket submission, knowledge base, team directory, dashboard, instructions and escalation policy
- styles.css: responsive styling and NovaTech-inspired dark navy / electric blue / cyan theme
- app.js: simulated ticket creation, ticket dashboard, knowledge base and scripted AI Coach
- novatech-logo.png: supplied NovaTech IT Support logo
- change-request.html: browser-based change request form (use Print / Save as PDF to save a completed copy)
- Change_Request_Form.pdf: blank printable/downloadable change request form
- pulsesync-logo.svg: original PulseSync vector logo asset retained in the project

HOW TO RUN
1. Extract the ZIP.
2. Open the pulsesync_website folder in Visual Studio Code.
3. Open index.html in Chrome or Edge, or use VS Code Live Server.
4. Internet access is needed for Bootstrap 5 and Bootstrap Icons CDNs.
5. Use Change Request in the navigation to open the form; use Download Change Form for the blank PDF.

ESCALATION RESPONSE TARGETS (from the NovaTech PulseSync SOP)
- Level 1 — Help Desk: response within 2 hours
- Level 2 — Specialist Support: response within 24 hours
- Level 3 — Smart Collaboration Room: response within 48 hours or longer for complex cases
These are response targets, not guaranteed resolution times.

IMPORTANT LIMITATIONS
- This is a front-end academic simulation. Tickets and team edits are stored in each browser's localStorage, not a shared database.
- The current PulseSync team roster is also included as the built-in default, so it loads on a new browser or website domain. Older generic sample team names are automatically replaced with the current roster.
- Browser storage is specific to the browser and website address; it does not sync between a local file, a hosted site, or another device.
- AI Coach is a scripted demonstration and is not connected to a live AI service.
- Do not enter real passwords or confidential information.
